# Design Permanent Rules

1. docs/DESIGN.md is the source of truth for every screen. If a task conflicts with it, stop and ask me.
2. No emojis in the UI.
3. No gradients, glass effects, or decorative shadows.
4. Do not default to grids of identical rounded cards. Use tables, ruled sections, and clinical-record layouts.
5. Triage colours are used only for urgency, and always paired with a shape and a text label.
6. Copy is plain, specific, and in sentence case. Errors say what went wrong and how to fix it. Buttons say what they do, such as 'Sign report', and the same action keeps the same name everywhere.
7. Meet WCAG AA contrast, visible keyboard focus, and 44px touch targets, and respect reduced motion.
8. Motion only in response to a user action or to show a meaningful change.
